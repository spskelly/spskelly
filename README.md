## Current focus

I'm packaging the reusable parts of my development workflow into a starter kit: Playwright verification and documentation, task-based agent orchestration, and repository/deployment configuration.

The Playwright template is public. The broader kit is still being extracted and documented.

## Engineering approach

Define acceptance criteria before implementation. Use deterministic fixtures where possible. Keep failure evidence available for diagnosis, distinguish generated artifacts from source, and make limitations explicit.

My goal is less repeated setup and supervision, without making the resulting software harder to review or maintain.
